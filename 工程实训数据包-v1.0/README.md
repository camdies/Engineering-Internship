## 三条必须先知道的事

### 1. 这不是干净数据 —— 这是有意的

这批数据里有大量真实缺陷：描述里残留 HTML 标签、时间字段语义错误、空间范围非法、
标题重复登记、某个字段整列全是 0……

**这些缺陷不是数据包做坏了，它们就是你的题目。** 详见 `data_dictionary.md`。

### 2. 这是教学抽样，两个地方要留意

抽样是**分层等比例**做的，各字段覆盖率与原库几乎一致（富集 0.96–1.14 倍），
所以字段层面的分析结果可以直接用。

但有两处**有意偏离**，做分布类分析时务必先读 `data_dictionary.md` 的抽样说明：

- 小类别（古气候、土壤土地、人文）**全量收进来了**，否则只有几十条，没法做任务；
- 缺陷记录（空间范围非法、时间倒挂、未来日期）占了 **12%**，是为了保证每层任务都有足够素材。

**结论不要推广到「全球地学数据的整体状况」**，全量数据（129,388 条）保留在导师侧用于最终评测。

### 3. 使用

```python
import geodata
con = geodata.connect()      # 已强制 query_only，写不进去
df  = geodata.load()         # 直接拿 DataFrame
```

需要中间结果就写到自己的文件里。改坏原始文件后，你和同学的结果就对不上了。

## 这个数据包里没有什么

- **没有检索索引。** 建立基线是你任务的一部分，我们故意不给。
- **没有 crossref 记录**（3.78 万条文献记录）——那些是论文不是数据集，已排除。
- **没有标注答案。** 哪些记录有缺陷、该怎么修，都要你自己判断。

## 可以做什么

四个方向，详见课堂导学：

1. **数据质量审计与修复** —— 清洗、校验、去重、字段语义规范化
2. **分类与标注质量改进** —— 分类纠错、受控词表映射、关键词补全
3. **发现与检索** —— 语义检索、跨语言检索、数据集推荐
4. **知识发现与智能体** —— 资源态势分析、缺口识别、数据助手
